# Требования к приложению «MyПицца»

## 1. Функциональные требования
- **ФТ-1 (Создание заказа):** Выбор пиццы из списка (5 позиций), размера (25, 30, 35 см), количества (1–50 шт.) и начального статуса.
- **ФТ-2 (Расчёт стоимости):** Автоматическое вычисление итоговой суммы по формуле `базовая_цена * коэффициент_размера * количество` с округлением до целых рублей.
- **ФТ-3 (Просмотр списка):** Отображение всех заказов в таблице с колонками: `№`, `Пицца`, `Размер`, `Кол-во`, `Сумма (руб.)`, `Статус`.
- **ФТ-4 (Редактирование и смена статуса):** При клике на строку в таблице данные загружаются в форму; нажатие «Изменить выбранный» обновляет запись и пересчитывает сумму.
- **ФТ-5 (Удаление):** Удаление выбранной в таблице записи по кнопке «Удалить выбранный».
- **ФТ-6 (Поиск):** Мгновенная фильтрация таблицы при вводе текста по номеру заказа, названию пиццы или статусу, а также кнопка «Сброс».

## 2. Нефункциональные требования
- **НТ-1 (Платформа):** Кроссплатформенность (Windows / Linux / macOS) на базе Python 3.11+ и стандартного модуля `tkinter`.
- **НТ-2 (Автономность):** Отсутствие внешних зависимостей и необходимости настраивать сервер баз данных.
- **НТ-3 (Надёжность ввода):** Защита от ввода отрицательных чисел, нуля, текста или значений больше 50 в поле количества с выводом понятного окна ошибки.
