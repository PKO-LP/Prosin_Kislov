# Руководство пользователя приложения «MyПицца»

## 1. Запуск программы
Убедитесь, что на компьютере установлен **Python 3.11 или новее**. В терминале из корневой папки проекта выполните:
```bash
python src/main.py
```
После запуска откроется главное окно программы с тремя демонстрационными заказами в таблице.

## 2. Основные операции
1. **Оформление нового заказа:**
   - В верхней панели выберите **Пиццу**, **Размер**, введите **Кол-во** (целое число от `1` до `50`) и выберите **Статус**.
   - Нажмите кнопку **«Добавить заказ»** — новая строка с рассчитанной суммой появится в конце таблицы.
2. **Изменение заказа или его статуса:**
   - Нажмите левой кнопкой мыши на нужную строку в таблице — её данные автоматически подставятся в верхнюю форму.
   - Измените нужные параметры (например, статус с `Готовится` на `Готов`) и нажмите **«Изменить выбранный»**.
3. **Удаление заказа:**
   - Выделите строку в таблице и нажмите **«Удалить выбранный»**.
4. **Поиск заказов:**
   - Введите в поле **«Поиск»** номер заказа (например, `2`), название пиццы (например, `пепперони`) или статус (`готов`) — таблица отфильтруется автоматически. Для возврата полного списка нажмите **«Сброс»**.
