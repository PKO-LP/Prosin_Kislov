# Техническое задание (ТЗ) на разработку «MyПицца»

## 1. Назначение и структура данных
Программа предназначена для автоматизации рабочего места оператора/кассира пиццерии. Каждый заказ хранится в оперативной памяти в виде словаря внутри списка `self.orders`:
```python
{
    "id": 1,                       # Уникальный порядковый номер (int)
    "pizza": "Пепперони",          # Наименование из меню (str)
    "size": "Большая (35 см)",     # Выбранный размер (str)
    "qty": 2,                      # Количество от 1 до 50 (int)
    "total": 1760,                 # Итоговая стоимость в рублях (int)
    "status": "Готовится"          # Статус: Готовится / Готов / Выдан (str)
}
```

## 2. Справочники цен и коэффициентов
- **Базовые цены (25 см, коэф. `1.0`):** Маргарита — 450 ₽, Гавайская — 520 ₽, Пепперони — 550 ₽, Четыре сыра — 600 ₽, Мясная — 650 ₽.
- **Коэффициенты размеров:** Маленькая (25 см) — `1.0`, Средняя (30 см) — `1.3`, Большая (35 см) — `1.6`.

## 3. Требования к интерфейсу
- Фиксированное окно `820x520` пикселей с заголовком «MyПицца — Учёт заказов пиццерии».
- Верхний блок: выпадающие списки (`Combobox`) для пиццы, размера и статуса, поле ввода (`Entry`) для количества.
- Панель управления: кнопки «Добавить заказ», «Изменить выбранный», «Удалить выбранный», поле «Поиск» и кнопка «Сброс».
- Основная область: таблица `ttk.Treeview` с 6 колонками и предзагрузкой 3 демонстрационных записей при старте.
