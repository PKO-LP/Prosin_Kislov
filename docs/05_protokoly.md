# Протоколы встреч по проекту «MyПицца»

## Встреча №1 — Старт проекта и согласование требований
- **Участники:** Заказчик («MyПицца»), команда разработки ([ФИО, группа]).
- **Обсуждаемые вопросы:** Определение меню пиццерии, размеров пицц, коэффициентов наценки и жизненного цикла статусов заказа.
- **Принятые решения:**
  1. Утвердить 5 базовых позиций меню («Маргарита», «Пепперони», «Четыре сыра», «Гавайская», «Мясная») и 3 размера (25, 30, 35 см).
  2. Утвердить цепочку статусов: `Готовится` → `Готов` → `Выдан`.
  3. Для версии v1.0 реализовать хранение данных в оперативной памяти с предзагрузкой 3 тестовых заказов.

## Встреча №2 — Демонстрация промежуточной версии (после Спринта 2)
- **Участники:** Заказчик («MyПицца»), команда разработки ([ФИО, группа]).
- **Обсуждаемые вопросы:** Проверка удобства таблицы заказов, редактирования записей и скорости поиска.
- **Принятые решения:**
  1. При клике на строку в таблице поля формы должны заполняться автоматически для быстрого редактирования.
  2. Добавить живой поиск по номеру, названию пиццы и статусу, а также кнопку «Сброс».

## Встреча №3 — Приёмка версии v1.0 (итоги Спринта 3)
- **Участники:** Заказчик («MyПицца»), команда разработки ([ФИО, группа]).
- **Обсуждаемые вопросы:** Проверка защиты от некорректного ввода и удаление ошибочных заказов.
- **Принятые решения:** Ограничить количество в одном заказе диапазоном `1–50` шт., утвердить версию **v1.0** к сдаче.
