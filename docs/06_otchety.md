# Отчёты о статусе разработки «MyПицца»

## Отчёт по Спринту 1 (Прототип и расчёты)
- **Что сделано:** Создана структура проекта, реализовано главное окно `PizzaOrderApp` на Tkinter, форма ввода, расчёт итоговой стоимости и добавление заказов в таблицу `Treeview`.
- **Проблемы и решения:** Потребовалось корректно округлять дробную стоимость при умножении на коэффициенты `1.3` и `1.6` — применено `int(round(...))`.
- **План на следующий спринт:** Добавить редактирование выбранного заказа, смену статуса и поиск.

## Отчёт по Спринту 2 (Основные сценарии)
- **Что сделано:** Реализовано автозаполнение формы при выборе строки (`<<TreeviewSelect>>`), обновление заказа (`update_order`) и живой поиск (`<KeyRelease>`).
- **Проблемы и решения:** При редактировании важно сохранять исходный `id` заказа — реализован поиск записи по `order_id` в списке словарей.
- **План на следующий спринт:** Добавить удаление заказа, проверку ввода количества и оформить документацию.

## Отчёт по Спринту 3 (Финализация v1.0)
- **Что сделано:** Реализовано удаление заказа (`delete_order`), строгая валидация поля «Кол-во» (`1–50`), добавлены демо-данные, выполнены ручные проверки в `tests/manual_checks.md` и оформлены все 7 документов.
- **Текущий статус:** Проект полностью готов к демонстрации и публикации в репозитории GitHub.
