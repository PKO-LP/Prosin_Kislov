# Устав проекта «MyПицца»

- **Название проекта:** MyПицца — автоматизированная система учёта заказов пиццерии.
- **Заказчик:** Сеть/точка пиццерии «MyПицца» (кассиры и администраторы смены).
- **Исполнители:** [Просин, Кисвло 11тэс].
- **Цель проекта:** Разработать простое и надёжное настольное приложение на Python (Tkinter) для быстрой регистрации заказов, автоматического расчёта стоимости и отслеживания этапов приготовления без ведения бумажных записей.
- **Сроки реализации:** 6 недель (3 спринта по 2 недели).
- **Границы проекта (v1.0):** CRUD-операции над заказами, расчёт цены по виду и размеру пиццы, живой поиск по таблице. Работа без внешней СУБД (хранение в памяти в рамках сеанса).
- **Критерии успеха:** Приложение запускается без сторонних библиотек, корректно считает сумму, блокирует ошибочный ввод количества и позволяет найти или обновить любой заказ за 2 клика.
