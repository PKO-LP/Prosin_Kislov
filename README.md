# MyПицца — Учёт заказов пиццерии

**Авторы:**[Просин Никита, Максим Кислов 11тэс]. **Срок:** 3 спринта по 2 недели (всего 6 недель). **Статус:** реализована версия v1.0.

Приложение **MyПицца** — это настольная программа для автоматизации работы кассиров и администраторов пиццерии (заказчик: **MyПицца**), позволяющая оформлять заказы на вынос и доставку, вести учёт и контролировать статусы приготовления без использования бумажных журналов.

## Функциональность

- **Добавление заказа:** выбор пиццы из меню («Маргарита», «Пепперони», «Четыре сыра», «Гавайская», «Мясная»), размера (25, 30, 35 см), количества и статуса.
- **Автоматический расчёт стоимости:** с учётом базовой цены, коэффициента размера (`1.0`, `1.3`, `1.6`) и количества.
- **Таблица заказов, поиск и фильтрация:** просмотр всех позиций, мгновенный поиск по номеру, названию или статусу (`Готовится`, `Готов`, `Выдан`), редактирование и удаление записей.

## Установка и запуск

1. Откройте папку проекта в терминале.
2. Убедитесь, что установлен **Python 3.11+** с модулем `tkinter` (внешние библиотеки не требуются).
3. Запустите приложение командой:
```bash
python src/main.py
```
Приложение содержит 3 демонстрационных заказа (`Пепперони`, `Маргарита`, `Четыре сыра`) для проверки работы поиска, изменения статусов и фильтрации.

## Технологический стек и этапы

- **Python 3.14** и **Tkinter** (`ttk`, `messagebox`) для графического интерфейса.
- **Хранение данных:** оперативная память (список словарей Python в рамках сеанса).
- **Спринты:** Спринт 1 (базовое окно и расчёты), Спринт 2 (поиск, редактирование и статусы), Спринт 3 (удаление, тесты и документация в `docs/`).

Полный текст документации и описание ручных проверок доступны в соответствующих файлах папок [docs/](docs/) и [tests/manual_checks.md](tests/manual_checks.md).
